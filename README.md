# Mind Dungeon: Shadowbound

Browserbasiertes Top-down-Lern-RPG mit KVT-III-Fragen (Konfrontationsverfahren).

## Spielen

Nach Aktivierung von GitHub Pages: https://topsoliino.github.io/mind-dungeon/

Alternativ `index.html` lokal im Browser öffnen.

## GitHub Pages aktivieren

Repository → **Settings** → **Pages** → **Build and deployment** → **Deploy from a branch** → Branch **main**, Ordner **/(root)** → **Save**.

## Steuerung

- WASD / Pfeiltasten: Bewegung
- Maus: Zielen
- Leertaste: Angriff
- Shift: Ausweichen
- E: Interaktion
- Q: Lernjournal

## Lerninhalte

Die Fragen basieren auf den bereitgestellten Folien **Kognitive Verhaltenstherapie III – Konfrontationsverfahren**. Es handelt sich um Lernmaterial, nicht um klinische Handlungsanweisungen.

## Updates

`index.html` enthält derzeit das Spiel und die Lernfragen. Neue Versionen können als Commits über GitHub aktualisiert werden. Vor Änderungen möglichst einen Feature-Branch verwenden.
